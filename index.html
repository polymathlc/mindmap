Keyboard Shortcuts

  • V - Select tool
  • R - Rectangle
  • C - Circle
  • D - Diamond
  • T - Triangle
  • A - Arrow (click origin, click target)
  • L - Line
  • X - Text
  • Tab - Add child (next level)
  • Enter - Add sibling (same level)
  • Delete - Delete selected
  • Ctrl+C - Copy
  • Ctrl+V - Paste
  • Ctrl+Z - Undo
  • Ctrl+Y - Redo
  • Ctrl+S - Save
  • Ctrl+O - Load
  • Ctrl+A - Select all
  • Esc - Deselect / Cancel
